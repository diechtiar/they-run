# THEY RUN

Standalone phone app. Do not import stacks, conventions, or names from other
products on this machine. The stack is this repo: `packages/hunt-engine` +
`apps/pwa` (Vite, TypeScript). The Android shell in `android/` is Capacitor
plus a location foreground service for screen-off nights. A small API only if
pair-run/presence is required. Not before.
